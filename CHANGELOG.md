# Changelog

## 0.5.0 — First public preview

- Native satellite video and audio continue behind a transparent Home overlay.
- Resident menu with invisible preparation and on-demand boot behavior.
- Correct WAM KeepAlive/hide lifecycle so the hidden overlay releases remote focus.
- Programme key forwarding to native Live TV while Home is visible.
- Generation tokens, SSE hide notifications and unresponsive-page fallback.
- LG-owned cold-start spinner with independent cleanup.
- English installation, compatibility, recovery and development documentation.
- Versioned release bundle, integrity checks, portable preflight and guarded restoration.

Runtime verified on one webOS SDK 5.6.2 TV. Independent fresh-install testing is pending.
